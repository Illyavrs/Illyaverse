# Card preview, navigation feedback and language controls

Visitor mode: **Operate**. A narrow extension of the established Serendipity catalogue, appearance controls, header and profile. Inherit the pure black default, configurable neutral glass, Nunito/Noto Sans TC, dense rows and shared shadcn controls. The user's latest screenshots take precedence over prior finish evidence.

## Direction contract

THESIS: Read every difficulty in a set without unintended navigation, see real request progress, and choose a readable language or identify a player's country without platform-dependent emoji rendering.

OWN-WORLD: Compact aligned fields and a single floating material; glass blur must sample the existing global scene. Keep one appearance control and stable document width while menus open. Self-host the original Twemoji flag artwork with its attribution, without adopting other product code or adding new imagery.

STORY: Search or filter the catalogue; hover a difficulty summary to inspect names and stars; open the set through its main identity link. Keyboard and touch offer the same read-only preview. Choose a full language name in the header. A profile's country uses the same recognizable flag artwork across Windows and other platforms.

FIRST VIEWPORT: A 36-pixel desktop search row with a vertically centred icon and aligned filters; phone controls retain 44-pixel targets. The header menu shows full language names and a single selected check. The progress bar is visible from the first pending frame. Panels continue to blur the background before and after navigation.

FORM: Direct source extension, no concept seed. Read-only preview fetches the complete known set, cancels stale requests and clearly labels fallback stored summaries. Native whole-root crossfade avoids placing a persistent backdrop root between panels and their scene. Minimum bar visibility is a legibility policy; pending ends when the actual request or navigation ends.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## Verification boundary

- Desktop 1440, user viewport 1280, phones 390 and 320; dark/light; zh-TW, English and Japanese.
- Verify actual PNG blur and progress pixels, not only computed CSS properties. Use original geometric test pixels rather than player artwork.
- Full official metadata preview is distinct from local storage and complete `.osz` availability. Reading it never publishes missing difficulties.
- Check hover, keyboard and touch; fallback, retry, withdrawal and stale responses; no difficulty links in card previews.
- Language persistence continues through the existing cookie and account setting. Unknown or unavailable flag assets retain the country code and readable name.
- Bounded screenshot review must include the latest user-reported defects. Fixture checks do not certify native client connectivity, score submission or upstream package downloads.
