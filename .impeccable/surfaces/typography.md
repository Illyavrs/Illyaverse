# Locale-aware rounded typography

Mode: Operate / Read refinement of the incumbent system. The user selected
Japanese Zen Maru Gothic and Traditional Chinese TaiwanPearl, then explicitly
chose to retain the current English face rather than obtaining Torus rights.

THESIS: Give Chinese and Japanese their requested rounded forms while keeping
the existing Latin identity, dense product hierarchy and wordmark geometry.

OWN-WORLD: Nunito remains authoritative for Latin and numerals in every locale.
TaiwanPearl-derived Illya Pearl supplies Traditional Chinese; Zen Maru
Gothic-derived Illya Maru supplies Japanese. Existing pure-black ground,
personal accent, neutral configurable glass and original character remain.

STORY: Locale changes select the appropriate Han forms. Japanese kana also
uses the Japanese family in mixed map titles. A script absent in the first
family continues through the other family and the user's system fallback.

FIRST VIEWPORT: Retain 15px dense body copy, incumbent 14–16px product labels,
distinct metadata and heading weights, existing 65ch introduction measure,
and unchanged 80px desktop / responsive Latin wordmark. No new type decoration,
copy, artwork, animation or card geometry belongs to this change.

FORM: Self-host original-licensed derivatives with renamed internal families,
retained copyrights and OFL. Two useful weights per CJK family, swap display,
locale UI common subsets plus nonoverlapping lazy 512-codepoint remainder
chunks retain every eligible source glyph for dynamic names and map titles.
No runtime font CDN or preloading the complete CJK repertoire.

FINISH: Root's initial desktop and Japanese phone inspection plus independent
mechanical scan inform this narrow refinement. Ship one combined bounded
browser inspection with the other current UI work; root owns the fresh finish
review, optional single correction confirmation and documentation handoff.
Browser probes must report actual platform-font glyph usage, local successful
font requests, lazy payload, mobile/zoom overflow and both themes. Generated
asset hashes and decoded cmap coverage must match the pinned upstream sources.
Synthetic glyph probes do not claim real native-client certification.
