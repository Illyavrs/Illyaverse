# Markdown formatting

You can use Markdown in your profile's "About me", in announcements and in the reason for a rank request.

| To get | Write |
| --- | --- |
| **Bold** | `**bold**` |
| *Italic* | `*italic*` |
| A link | `[text](https://example.com)` |
| A heading | `## Heading` |
| A list | start each line with `- ` |
| A numbered list | start each line with `1. ` |
| A quote | `> quoted text` |
| Inline code | `` `code` `` |
| Strikethrough | `~~text~~` |
| A table | separate columns with `\|` and put `---` under the header row |

## Limits

- **No HTML.** HTML tags you write are ignored.
- **No images.** They are not loaded, so nobody can be tracked through an image. Paste a link instead.
- Every link opens in a new tab and is marked as user content.
- Chat messages are plain text and do not use Markdown.

## Visual editing and BBCode

Your biography, announcements and beatmap nomination/review reasons can use Markdown or BBCode. The shared visual editor supports bold, italics, strike-through, headings, links, lists, quotes, code and tables, with underline available in BBCode. You can switch to source or preview while keeping your draft. Format changes convert the current editor content; Markdown has no color or spoiler syntax, so these BBCode styles become plain content when converted to Markdown.

Common BBCode tags include `[b]bold[/b]`, `[i]italic[/i]`, `[u]underline[/u]`, `[s]strike[/s]`, `[url=https://example.com]link[/url]`, `[quote]quote[/quote]`, `[code]code[/code]` and `[list][*]one[*]two[/list]`. Color, size, center and spoiler tags are also supported. Unknown tags remain visible text. Image tags become links instead of loading external tracking images.

The chosen format is stored alongside each text. Existing content remains Markdown. Profile biographies allow 4,000 characters, announcements 20,000 characters and 64 KiB, and nomination/review reasons 1,000 characters. Limits include source markup, not just visible text.
