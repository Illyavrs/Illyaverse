---
title: "公告"
---

公告由管理員撰寫並明確發布。首頁顯示近期已發布公告；`/news` 提供分頁列表，
`/news/{id}` 顯示完整內容、作者與發布時間。未發布或已撤下公告的公開詳情回傳
404，即使讀取者是管理員。

具備 `announcements.manage` 的工作人員可從管理面板的公告區
建立草稿、編輯、發布與撤下公告。建立時一律是草稿；查看或切換頁面不會自動
發布。公告使用純文字，保留換行與一般文字；不執行 HTML、JavaScript 或嵌入媒體。

| API                                                 | 行為                                                              |
| --------------------------------------------------- | ----------------------------------------------------------------- |
| `GET /api/v1/announcements?page=1&page_size=12`     | 只列出已發布公告，依發布時間與 ID 倒序                            |
| `GET /api/v1/announcements/{id}`                    | 取得已發布公告；其他狀態為 404                                    |
| `GET /api/v1/admin/announcements?status=all&page=1` | 依 `all`、`draft`、`published`、`archived` 分頁；需要公告管理權限 |
| `POST /api/v1/admin/announcements`                  | `title`、`body`；建立草稿並回傳 201                               |
| `GET /api/v1/admin/announcements/{id}`              | 讀取指定公告的最新版本，包括非公開狀態；需要公告管理權限          |
| `PATCH /api/v1/admin/announcements/{id}`            | 完整 `title`、`body`、`status`、目前 `revision`；更新成功遞增版本 |

標題接受 1–160 個字元；內文接受 1–20,000 個字元且不超過 64 KiB。
兩者去除首尾空白，內文的 CRLF 轉成 LF；除了內文換行與 Tab，拒絕控制字元。
公告狀態為 `draft`、`published` 或 `archived`。由非公開狀態重新發布會設定新的
發布時間；編輯仍已發布的公告保留原發布時間，撤下保留上次發布時間。

更新使用版本檢查。另一位編輯者先儲存時，後到的更新回傳 409
`announcement_conflict`；本機草稿保留，編輯者可明確載入最新版本再修改。
每次寫入會在同一資料庫交易中重新驗證登入與權限，並提交稽核紀錄。
授權失效、版本衝突或交易失敗不會留下部分修改。

未儲存的文字暫存在目前分頁的記憶體中。在網站內使用瀏覽器上一頁、下一頁
離開公告編輯區，再返回時，編輯器會重新驗證權限與公告版本並取回草稿。
這不會自動儲存或發布；捨棄修改需要明確確認。登出、切換帳號或失去管理權限
會清除暫存，重新整理或關閉分頁後也不會保留。

公告 API、管理區入口與暫存草稿均使用 `announcements.manage`；不需要另外
授予 `admin.view`。2026-10-09 的網站權限調整已有針對性瀏覽器驗證，尚未部署至保留的
本機站台；其公告資料與原有發布流程不受此次原始碼調整影響。

此功能不會自動發送聊天、電子郵件或其他通知，也不會預先建立範例公告。
繁中、英文與日文適用於介面與日期格式；公告內容保留作者輸入的語言。
相關權限請見[權限管理](/docs/operate/permissions)。
