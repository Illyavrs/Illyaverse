這份文件寫給**管理員**。如果你是玩家，想知道怎麼連線與遊玩，請看網站內的「連線教學」與玩家說明。

## 你會用到的元件

| 名稱 | 角色 |
| --- | --- |
| Serendipity | 網站（Next.js） |
| Sanctuary | 網站 API 與資料（Rust） |
| Resonance | osu! stable／lazer 的遊戲協定閘道（Rust） |
| Kaleidoscope | 給玩家用的連線啟動器 |
| Transfiguration | Kaleidoscope 為 lazer 載入的連線橋接 |
| PostgreSQL／Caddy | 資料庫與反向代理（自動 HTTPS） |

## 從哪裡開始

1. [快速開始](/docs/quickstart)：十分鐘內在本機跑起來。
2. [Docker 部署](/docs/deploy/deployment)：正式網域、HTTPS、環境變數、備份與還原。
3. [權限與營運](/docs/operate/permissions)：角色、管理員工具與帳號復原。
4. [客戶端與連線](/docs/clients/connection)：玩家如何連上，以及 Kaleidoscope 的發行方式。
5. [協定與驗證參考](/docs/reference/protocol-compatibility)：目前哪些功能已驗證、哪些仍在測試。

<Callout type="warn">
Stable 與 lazer 的登入、遊玩、聊天與成績提交已有測試；多人遊戲與觀戰仍在驗證中。對外開放前，請在你選定的客戶端版本實測。
</Callout>
